# Curology

Luxury skincare storefront concept built with HTML, CSS, and JavaScript.

## Run locally

Open the `index.html` file in a browser, or serve the folder with a local static server.

## Notes

This single-folder concept includes the landing page, product catalog, category filters and search, product details, concern-based routine discovery, a localStorage shopping bag, and a front-end demo checkout. Newsletter validation, ingredient disclosures, manually controlled testimonials, and the gallery lightbox are also included.

Checkout does not collect payment or send order data to a service. Cart contents are stored in the browser's localStorage for demonstration purposes.
